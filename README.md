A two-line robot confession: the machine admits it sent the shopping list to its owner's boss instead of their partner, and resolves to read the recipient twice before pressing send. One specific, human-scale slip; one lesson that follows from it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) writes `entry.txt` — exactly two sentences — to `$MAKEFUN_OUTPUT_DIR` (default `/output`). No network, no randomness, no external files — two runs write byte-identical output.
